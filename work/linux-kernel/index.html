使用 C 与 x86 汇编构建类 Linux 内核，涵盖虚拟内存、文件系统、系统调用、驱动与调度；四人团队协作。

问题

从底层构建一个操作系统，能把教科书中的进程、内存与设备抽象变成相互配合的真实模块。

Kernel fundamentals

Scheduling & devices
实现键盘、RTC、PIT 等设备驱动，支持多进程切换与多终端调度。
