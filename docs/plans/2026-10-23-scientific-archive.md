# Scientific Archive Implementation Plan

**Goal:** 将个人网站完整重设计为科学影像档案：用原创计算图形和科学隐喻呈现个人作品、研究、写作与生活。

**Architecture:** 保留 Astro 静态内容、原有 URL 和归并结果；重建共享视觉、首页、作品目录及页面开场。科学形态使用本地数学生成的 SVG 和轻量 Canvas，静态图形为无脚本与减少动效提供完整回退。科研结论与视觉习作明确区分。

**Tech Stack:** Astro、原生 CSS/JS、Canvas 2D、SVG；不为展示动效引入应用框架或全屏视频依赖。

## 1. 原创视觉与共享布局
- 新建 `src/components/FieldVisual.astro`、`src/components/Instrument.astro` 和 `src/scripts/instrument.js`。
- 从参数方程生成场、分支和地形。指针仅改变观察角度；按钮切换结构；支持暂停、减少动效、离屏停止及无脚本静态回退。
- 将旧基础样式和客户端脚本重命名为 foundation.css、site.js；移除 zine.css，引入 archive.css。
- 重建品牌、导航、页脚、图标与分享封面；删除用户可见的花园概念。

## 2. 首页与作品
- 首页：个人身份 → 原创复古计算装置与形态实验 → 三个重点项目的问题/模型/实验 → 研究与写作 → 真实摄影。
- 作品目录采用档案条目、独立图形与材料，保留六个完整案例。
- 案例、研究、写作、生活和关于页面统一新的颜色、字体、层级及图像语言；正文和真实研究配图保持可读。

## 3. 验收与发布
- 构建与内部链接/公式/内容归并检查。
- 桌面和手机主页面、全部文字和历史入口、搜索、画廊、兼容 URL；新增仪器交互、暂停/减少动效、无脚本及多屏宽检查。
- 复看桌面/手机截图，从排版、留白、视觉层级、色彩、动效、微交互、响应式和原创性修正具体问题。
- 提交源码，发布原址，验证源码 CI、Pages、精确线上版本和 Doc/CV 404。

## 参考边界
用户提供的 Kimi 影片描述作为美术方向；官方品牌手册用于科学与人文、结构网格、解码质感等原则。影片日期、镜头数和模型版本不作为本站可核实事实发布。所有新增形态、装置、文案与构图原创，不使用 Kimi Logo、影片、提示词、视频素材或品牌资产。
