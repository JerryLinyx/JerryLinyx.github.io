# 科学影像档案 · 设计与验收记录

日期：2026-10-23。正式网址：https://jerrylinyx.github.io/。

## 最终设计

原有花园与纸刊叙事已退出当前界面，首页重建为个人观察站。冷米白与石墨黑承载内容，淡紫、灰绿在形态标本和档案页面形成有区别的阅读场景。原创 CSS 复古计算装置展示本地数学形态：场、生长和地形。指针可改变观察角度，按钮切换结构；没有视频素材、品牌拷贝、音频或强制滚动。

首页按个人身份、形态观察仪、三个项目的问题、研究与文字、真实摄影展开。六个作品使用档案目录入口；案例保留实际图片、方法、个人职责和可复核结果。论文、42 篇文字、9 张照片、历史内容与兼容链接继续完整保留。数学形态明确标注为视觉习作，不将其作为实验数据。Kimi 的影片/Logo/品牌资产未复制；用户提供的版本与镜头信息也未作为事实写入网站。

## 八个维度复看

| 维度 | 检查与修正 |
| --- | --- |
| 排版 | 使用本地 Instrument Serif 正体/真实斜体、中文宋体和清晰正文；等宽小字仅作附属档案标记。保持一个主标题，正文、代码、公式和目录分层可读 |
| 留白 | 首屏给计算装置、文字和控制区分别留出空间；修正控制区挤入页尾的间距；长内容以场景变化分段 |
| 层级 | “问题 → 模型/方法 → 项目记录”构成叙事；作品、写作、论文和个人摄影各有独立入口 |
| 色彩 | 冷纸、石墨与淡紫构成主轴；修正小号编号、标本标签、注记与阅读辅助文字的对比度 |
| 动效 | 短入场、轻量图形旋转、指针观察角度、滚入展开；无闪烁和自动快速剪辑。Canvas 约 30fps、DPR 上限 2、离屏和后台停止 |
| 微交互 | 原生结构按钮、暂停/恢复、键盘操作、清晰焦点；搜索/筛选/查询状态、画廊和阅读控制保持有效 |
| 响应式 | 1440/390px 主要页面；320/768/1024px 补充布局。修正研究页论文标记继承横向 flex 导致的溢出，手机装置和项目自然纵向展开 |
| 原创性 | 数学方程生成的 SVG/Canvas、CSS 装置、本人案例与摄影；借鉴科学隐喻和档案语法，不复刻影片或商业模板 |

## 本地验证

- 静态构建成功；195 个 HTML 页面（含兼容入口）。
- 42 篇独立正文、2 个合并入口、10 个共用历史正文及 55 份媒体归并校验通过。
- 页面/内容/交互：108 项通过，包括全部正文、历史记录、主页面、搜索、画廊和旧 URL。
- 无障碍：34 个桌面/手机 axe 场景，零 WCAG 2 A/AA 与 2.1 AA 标签下的违规。自动规则范围不等同于完整人工无障碍认证。
- 观察仪与补充布局：22 项通过，覆盖结构选择、暂停画面稳定、系统减少动效、键盘、无脚本静态回退，以及 320/768/1024px 的 15 个布局场景。最终补充无脚本导航和禁用无功能的形态按钮。
- 普通动态模式与减少动效模式均查看过截图。最终视觉材料和机器检查结果保存在被忽略的 `output/playwright/archive/`。

环境为 macOS 实际 Chrome，包括不同模拟屏宽；不宣称物理 iPhone/Safari 已实测。没有外部分析或运行时第三方字体/视频请求。原有 Mermaid 仍按阅读页需求加载，图形展示未引入 Three.js/React 等依赖。
