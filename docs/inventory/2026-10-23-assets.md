## 保留与暂不展示

互补的 Flow 英文材料、三份 LLM 文献索引等保留为源资料，不按同名或相似标题粗暴删除。显式草稿、Hugo 测试页与旧框架配置不加入网站主导航。旧 Hugo DPI 记录属于早期源快照，当前 DPI 笔记是现行入口。未核实的文献归属和仓库来源不被补写为个人成果。所有移除内容可通过本仓库既有 Git 历史恢复，未修改外部 Obsidian 笔记库。

## 呈现规则

文字以原始来源为准（原简历、原项目数据、docs/intro.md、原影集），后期改写的文案已移除。每个主题只有一个正式页面：作品、写作、生活、关于；论文位于关于页，阅读路线位于写作页，旧 /research/ 与 /life/singapore/ 地址跳转。历史存档位于页脚。Doc、CV 仓库保留，站点继续下架，URL 不恢复。视觉规范见 docs/plans/2026-10-23-site-redesign.md。完整条目、媒体归并映射、源资料去向与 40 个公开仓库元数据见同目录 JSON 文件。
