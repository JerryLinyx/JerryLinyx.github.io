## 保留与暂不展示

互补的 Flow 英文材料、三份 LLM 文献索引等保留为源资料，不按同名或相似标题粗暴删除。显式草稿、Hugo 测试页与旧框架配置不加入网站主导航。旧 Hugo DPI 记录属于早期源快照，当前 DPI 笔记是现行入口。未核实的文献归属和仓库来源不被补写为个人成果。所有移除内容可通过本仓库既有 Git 历史恢复，未修改外部 Obsidian 笔记库。

## 呈现规则

首页是精选编辑索引，四类内容平等入口，不将所有文件铺满首屏。作品讲问题、设计与结果；研究连接论文与学习；写作一题一入口，保留全文搜索与主题筛选；生活使用真实摄影，放大后保持原始色彩。关于我承载简介与可打印履历；历史存档位于次导航。Doc、CV 仓库保留，站点继续下架，URL 不恢复。

视觉采用纸色、墨色与单一钴蓝强调，保留真正的内容、必要的留白和印刷片段感。参考海报的构图语言，网页正文不使用难以阅读的海报微缩字号。完整条目、媒体归并映射、源资料去向与 40 个公开仓库元数据见同目录 JSON 文件。
